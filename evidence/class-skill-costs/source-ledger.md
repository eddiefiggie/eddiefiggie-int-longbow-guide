## Positive cost and maximum rules

- Class_skill: “Class skills are skills that are bought on a one point for one rank basis, as opposed to Cross-class skills which are bought at a two points for one rank basis.”
- Skill_point: “Each skill point buys 1 rank in a class skill”
- Skill_point: “Each skill point buys 0.5 ranks in a cross-class skill”
- Skill_point: “Multiclass characters purchase ranks using the costs for the class currently being advanced, but maximum ranks is level + 3 if the skill is a class skill for any trained class.”
- Cross-class_skill: “Taking even a single level of a class that gets a certain skill as a class skill permanently raises that skill's maximum rank to (3 + character level) – the same maximum formula as a pure class skill – even if the character later takes more levels in classes where it's a cross-class skill again.”
- Cross-class_skill: “Note that the cost of a rank at each level still depends on whether the skill is class or cross-class for that level-up.”
- Skill_point: “All skill points must be spent during level up. You cannot save them.”

These rules support 1 point per rank on a level advancing a class that has the skill, otherwise 2 points per rank where training is allowed. A prior Rogue level raises maximums for its class skills, not every later purchase's price. Having a past-life feat is not the same thing as advancing that class.

## Publication-safe narrow rule

“Each rank costs 1 skill point when the skill is a class skill of the class being advanced, or 2 points when it is cross-class and can be trained. Taking Rogue does not make every later level use Rogue prices: it raises the maximum for Rogue class skills to character level + 3, while each later purchase uses that level's class. Use the named class-skill examples and the actual class being advanced, including the chosen archetype, rather than assuming every past-life-class level has the same prices.”

This is a rule summary, not an instruction to change selected ranks or targets.
